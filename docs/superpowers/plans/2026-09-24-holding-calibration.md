# 持仓校准与无买入记录卖出

用户确认：卖出后自动扣减持仓；漏记买入时可校准持仓数量。

## 设计

- 新增 `adjust` 流水，数量表示校准后的绝对持仓，价格表示平均成本（可空）。不产生现金流或已实现收益。同日按流水 ID 顺序生效。
- 已有唯一手填股票持仓首次买卖时，保存一条交易前的期初校准，原持仓转为流水驱动，保留 ID、行情及研究关联。不合并身份相同的多个持仓。
- 支持平台持仓页校准和交易页录入/修改校准。卖出以按时间回放的可用数量为准；数量不足提示校准。
- 缺失成本时不把卖出收入当收益，记录收益不完整标志；补齐原校准成本后重新计算。
- 校准记录参加备份、恢复和 CSV 导入；校准不覆盖此前已实现盈亏。
